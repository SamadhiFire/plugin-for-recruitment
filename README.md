# 求职简历助手

本地运行的 Chrome/Edge 扩展：从结构化简历主库生成候选文案，读取招聘页面的可编辑 DOM 字段，自动识别并补齐教育、实习和项目条目，再由你在预览中确认后一次填入。它不会自动点击保存、下一步、附件上传或最终提交。

## 已实现

- Chrome/Edge Manifest V3 侧边栏扩展；已针对 OPPO、字节跳动、小米验证结构，并可在用户主动点击扩展后动态识别其他招聘网站。
- 不依赖截图：内容脚本读取 `input`、`textarea`、`select`、`contenteditable` 等真实表单元素，并派发网页框架需要的 `input/change/blur` 事件。
- 三层字段理解：结构化 ID/DOM 与招聘站点规则优先，通用标签和上下文语义其次，仍不明确的字段由千问结合完整页面结构与简历主库识别。
- “扫描并生成整页方案”会预览所有动作；可自动点击页面中的“添加”补齐缺失的教育、实习和项目记录，但保留网页上原有且无对应关系的记录。
- 简历中明确存在的事实可默认勾选；千问针对开放题生成的内容一律标记“需确认”并默认不勾选。确认后点击“一键填入已勾选项”，仍不会点击招聘网站的保存或提交。
- 可将简历之外、你已经填写过的补充答案保存到本机 `data/answers.memory.json`，下次换网站复用。
- 本地简历主库在 [data/resume.profile.json](data/resume.profile.json)，支持在侧边栏编辑、保存及版本号递增。
- 千问通过本地服务调用；API 密钥只放在 `.env`，扩展代码、浏览器存储和 Git 均不包含密钥。
- AI 产品经理、产品运营/商业化两个内容侧重；固定分点、保留真实指标、不得臆造事实等约束。

## 启动

1. 安装 Node.js 20 或以上版本。
2. 双击 [启动助手.cmd](启动助手.cmd)，或在此目录打开 PowerShell，运行：

   ```powershell
   npm run start
   ```

3. 打开 `chrome://extensions` 或 `edge://extensions`，启用“开发人员模式”。
4. 点击“加载已解压的扩展程序”，选择本目录下的 `extension` 文件夹。
5. 打开已登录的招聘页面，点击工具栏中的“求职简历助手”；在侧边栏点击“扫描并生成整页方案”，检查候选清单后，再点击“一键填入已勾选项”。

代码更新后，请在 `chrome://extensions` 或 `edge://extensions` 对本扩展点击一次“重新加载”，再刷新招聘页面。

本地服务必须持续运行。关闭“启动助手”窗口/PowerShell 后，扩展仍可读取页面字段，但无法调用千问或更新磁盘主库。启动脚本会优先识别常见的 Windows Node.js 安装位置（也包含本机的 `D:\Program Files\nodejs\node.exe`）。侧边栏顶部的“本地服务设置”可粘贴或替换主 API Key；保存后只会写入本机 `.env`，输入框不会回显密钥。`.env` 可同时配置 `DASHSCOPE_API_KEY_FALLBACK`，主密钥请求失败时自动尝试备用密钥。

## 更新简历

推荐在侧边栏的“简历主库”编辑 JSON 并保存。每次保存都会递增 `meta.version`，不会让模型替你篡改原始文档。主库保存在本机 `data/resume.profile.json`，因此换到字节、小米或其他已适配网站时，姓名、教育、经历、技能等重复内容无需重新录入。

如果你更新了 Word 简历，请将确认过的变更同步到 `data/resume.profile.json`：时间、指标、公司/项目名和链接应优先更新；缺少依据的数据保持“待确认”。

## 安全与边界

- 不要把 `.env` 发给他人，也不要提交到 Git；它已经被忽略。
- 验证码、短信验证、登录和附件上传必须手动操作。
- 扩展不会绕过网站限制，不会读取 HttpOnly Cookie，也不会提交你的申请。
- 页面升级后若字段无法识别，可先刷新字段列表；自定义日期选择器、级联下拉框等仍可能需要增加站点适配规则。
